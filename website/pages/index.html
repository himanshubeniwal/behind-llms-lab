What this is

Two parts, one story

First you learn to drive the machine. Then you use it to build the thing everybody talks about, and you see that there is no magic inside.

Part 1 · on the cluster

The HPC lab

You log in to the ZIH clusters, send your first Slurm jobs, get a GPU, train a tiny GPT and run a real language model. Every exercise is one folder with a small Python script and the job script that runs it.

  • your first batch job, and how to cancel one
  • one GPU, and how much faster it is than a CPU
  • a learning-rate sweep with a job array
  • a pretrained LLM that answers a file of prompts

Part 2 · in a notebook

The crash course

Three notebooks that build a language model from scratch and then look inside real ones. They run in Google Colab and need no big GPU.

  • tokens, a small BPE and a model that only counts
  • self-attention, a Transformer block and a tiny GPT
  • perplexity, surprisal, zero-shot labels and embeddings
  • exercises at the end of every notebook

Quick start

Three ways in

Pick where you want to work. The cluster needs the university network or the VPN, and your ZIH login.

Log in to a GPU cluster and get the lab kit. Then continue with Setup.

ssh @login1.alpha.hpc.tu-dresden.de git clone {{clone}} cd behind-llms-lab/hpc_lab

Open a notebook with one click on the Notebooks page. Or, inside Colab: File > Open notebook > GitHub, paste himanshubeniwal/behind-llms-lab and pick a notebook.

For notebooks 5 and 6, switch to a T4 GPU under Runtime > Change runtime type. Notebook 4 is fine on a CPU.

The notebooks and the scripts also run on a normal laptop, only slower. You need a recent Python 3 (the cluster uses 3.12).

git clone {{clone}} cd behind-llms-lab python3 -m venv .venv && source .venv/bin/activate pip install torch numpy matplotlib tqdm transformers accelerate jupyter jupyter lab notebooks/
